# I1 — Página 404 do blog + símbolo `laco` no sprite (Onda 1, Infra)

**Objetivo.** Quando alguém abre um endereço inexistente em `/blog/…`, o Cloudflare serve a `404.html` mais próxima do caminho
(`not_found_handling = "404-page"` em `frontend/wrangler.toml`). Criar `frontend/blog/404.html`: texto educado + 2 ícones clicáveis
(plataforma e Instagram da Liga), `noindex`. Também desenhar o símbolo `laco` (laço da campanha) no sprite.

## Passo 0 — ler
`docs/blog/fichas/_REGRAS.md`; `docs/blog/WIREFRAME.md` (regras globais, sprite); `frontend/blog/icones.svg` (formato dos símbolos);
`frontend/blog.css` linhas 1–60 e a regra `.blog-botao` (Grep) para reaproveitar tokens; o `<head>` gerado em
`frontend/scripts/build-blog.js:265-279` (copie a CSP de lá, linha 172-173). Confirme com Grep `not_found_handling` em `frontend/wrangler.toml`.

## Dono de (só estes)
- CRIA `frontend/blog/404.html`
- EDITA `frontend/blog.css` (só **acrescenta** uma seção no fim: `/* ===== 404 do blog ===== */`; não mexa no resto)
- EDITA `frontend/blog/icones.svg` (só **acrescenta** `<symbol id="laco">`)
- Proibido: `frontend/404.html` (raiz), `build-blog.js`, `build.js`, qualquer outro arquivo.

## Requisitos
1. `404.html`: `<!DOCTYPE html>`, `lang="pt-BR"`, CSP `<meta>` **igual** à do gerador, `viewport`, `color-scheme light dark`,
   `theme-color #0f6f62`, `<meta name="robots" content="noindex">`, `<title>Página indisponível · Blog LAIFT</title>`,
   CSS só por `<link>`: `/modulos/shared/laift-tokens.css` e `/blog.css` (caminhos **absolutos**, a página é servida em qualquer `/blog/…`).
   Sem `<script>` (não precisa de JS), sem `style=""`.
2. Corpo: `body.blog-page.blog-404` → `a.blog-skip` → `header.blog-topo` com a marca (igual ao gerador: `a.blog-topo__marca href="/blog.html"`
   com `img /modulos/cracha/laift-marca.png alt="LAIFT" width=40 height=40` + "Blog LAIFT") → `main#conteudo.blog-404__area` com:
   - `h1`: "Esta página não está disponível no momento"
   - `p.blog-404__texto`: "Em breve você poderá acompanhar este conteúdo por aqui. Enquanto isso, acesse a plataforma e fique por dentro das novidades da LAIFT."
   - `ul.blog-404__atalhos` com 2 `li > a.blog-404__atalho`:
     a) `href="/"` → `svg.blog-icone.blog-404__icone` `#inicio` + `span.blog-404__rotulo` "Acessar a plataforma" + `span.blog-404__sub` "laift.com.br";
     b) `href="https://www.instagram.com/laift.liga" target="_blank" rel="noopener noreferrer" aria-label="Instagram da Liga LAIFT, abre em nova aba"`
        → ícone `#ig` + "Instagram da Liga" + sub "@laift.liga".
   - `p.blog-404__voltar > a href="/blog.html"` "Ver todos os posts do blog".
   Ícones: `<svg class="blog-icone blog-404__icone" aria-hidden="true" focusable="false"><use href="/blog/icones.svg#ID"></use></svg>`.
3. `blog.css` (seção nova no fim): `.blog-404__area` centrado, largura máx. ~40rem, respiro vertical; `.blog-404__atalhos` em grade
   1 coluna no celular e 2 colunas a partir de 480 px; `.blog-404__atalho` cartão com borda/véu dos tokens, `min-height: var(--laift-touch, 44px)`
   (o cartão tem ~120 px), ícone 48 px, foco visível (`:focus-visible` com contorno), `:active { transform: scale(var(--press-scale)) }`,
   `:hover` só em `@media (hover: hover)`, transição só de `transform`/`opacity` e desligada em `prefers-reduced-motion: reduce`.
   Funciona em claro e escuro (só `var(--…)`).
4. `icones.svg`: `<symbol id="laco" viewBox="0 0 24 24">` = laço de conscientização (alça arredondada em cima, duas pontas cruzadas embaixo),
   desenho próprio, cada forma com `fill="none" stroke="currentColor" stroke-width="1.8" stroke-linecap="round" stroke-linejoin="round"`.

## Aceite (de `frontend/`, Bash)
```
grep -c 'name="robots" content="noindex"' blog/404.html            # 1
grep -cE 'style=|<script' blog/404.html                             # 0
grep -c 'href="https://www.instagram.com/laift.liga"' blog/404.html # 1
grep -c 'id="laco"' blog/icones.svg                                 # 1
node --test scripts/build-blog.test.mjs                             # verde
node scripts/build.js && test -f dist/blog/404.html && echo OK-404
```
Relatório conforme `_REGRAS.md` (≤ 12 linhas).
