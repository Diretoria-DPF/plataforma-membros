## `roteiro.md`
1. Aviso no topo: "Kit para a Liga publicar manualmente. Conferir antes de postar; os números têm fonte na seção Fontes."
2. **Legenda** (≤ 2.200 caracteres): 1ª linha que prende a atenção (sem clickbait), 3–5 parágrafos curtos, chamada "Leia a publicação completa no blog da LAIFT:
   laift.com.br/blog/outubro-rosa-2026 (link na bio)", o aviso de saúde ("Conteúdo educativo. Não substitui consulta com profissional de saúde."),
   e "Fontes:" com 3–6 fontes curtas (órgão + ano). Emoji permitido na legenda, no máximo 6, discretos.
3. **Hashtags:** 8–12, em português, relevantes (ex.: `#OutubroRosa #CancerDeMama #SaudeDaMulher #Prevencao #AutoCuidado`), sem marcar pessoas nem perfis.
4. **Roteiro do carrossel:** tabela de 8–10 slides: nº | tipo | título (≤ 8 palavras) | texto (≤ 25 palavras) | fonte curta | texto alternativo (≤ 250 caracteres).
   Sequência sugerida: capa → o que é → números (1 número grande) → sinais de alerta → conheça suas mamas → rastreamento no SUS → 2 mitos × verdades →
   hábitos (emoji permitido neste slide) → direitos (3 principais) → fecho (blog + @laift.liga + aviso).
5. **Checklist de publicação** para a Liga (5 itens: conferir números com a seção Fontes, texto alternativo em cada imagem, ordem dos slides, link na bio, horário).

## `slides.json` (lido pelo G2)
```json
{ "tamanho": [1080, 1350],
  "rodape": "@laift.liga · laift.com.br/blog",
  "slides": [ { "n": 1, "tipo": "capa|texto|numero|lista|mitos|habitos|fecho", "titulo": "…", "texto": "…",
                "itens": ["…"], "numero": "78.610", "numeroRotulo": "…", "fonte": "INCA, 2025", "alt": "…" } ] }
```
Campos opcionais por tipo: `numero`/`numeroRotulo` (tipo `numero`), `itens` (tipos `lista`, `mitos` — prefixe "Mito:"/"Verdade:", `habitos` — cada item começa
com 1 emoji). Mesmo texto do roteiro. Sem nome de pessoa, sem e-mail, só fatos CONFIRMADO/CORRIGIDO.
