# G2 — Gerador dos slides PNG 1080×1350 do carrossel (Onda 3, Instagram)

**Objetivo.** Um script que lê `docs/campanhas/outubro-rosa/instagram/slides.json` e gera `slide-01.png` … `slide-NN.png` (1080×1350) com
Playwright (já instalado em `frontend/node_modules`). Começa quando G1 terminar.

## Passo 0 — ler
`docs/blog/fichas/_REGRAS.md`; `docs/blog/fichas/G1.md` (formato do `slides.json`); o `slides.json` e o `roteiro.md` do G1;
`frontend/scripts/e2e/harness.js:56-62` (como o projeto carrega o Playwright); Grep `--laift-primary` em `frontend/modulos/shared/laift-tokens.css` (verde da marca).

## Dono de
- CRIA `frontend/scripts/campanha-slides.mjs` (ESM, cabeçalho de copyright; uso: `node scripts/campanha-slides.mjs [caminho/slides.json]`,
  padrão `../docs/campanhas/outubro-rosa/instagram/slides.json`; saída na mesma pasta do JSON)
- CRIA os PNGs `docs/campanhas/outubro-rosa/instagram/slide-NN.png`
Nada mais (não adicione script ao `package.json`).

## Requisitos
1. `createRequire(import.meta.url)` + `require('playwright')`; `chromium.launch()`; página 1080×1350, `deviceScaleFactor: 1`; um `page.setContent(html)` por slide;
   `page.screenshot({ path, clip: { x: 0, y: 0, width: 1080, height: 1350 } })`. Nenhum acesso à rede (tudo embutido; o logo
   `frontend/modulos/cracha/laift-marca.png` vira `data:` URI, **sempre sobre placa clara**).
2. Todo texto do JSON é escapado (`& < > " '`) antes de entrar no HTML. Fonte do sistema (`system-ui, "Segoe UI", Roboto, sans-serif`;
   emoji com `"Segoe UI Emoji", "Apple Color Emoji", "Noto Color Emoji"`).
3. Visual: fundo claro com faixa/acento rosa (mesmo espírito de `frontend/blog-campanha.css`, se já existir) e detalhe no verde LAIFT; título ≥ 64 px,
   texto ≥ 34 px, rodapé ≥ 26 px com `rodape`, `fonte` do slide e "n/N"; margens ≥ 80 px; contraste de texto ≥ 4.5:1. Layout por `tipo`
   (`capa`, `texto`, `numero` com número enorme, `lista`, `mitos`, `habitos`, `fecho`).
4. **Checagem de transbordo:** depois do `setContent`, avalie no navegador se algum bloco de texto tem `scrollHeight > clientHeight` ou sai da área segura;
   se sim, reduza a fonte em passos de 2 px até caber (mínimo 30 px no texto) e, se ainda não couber, termine com erro dizendo o slide.
5. Ao final imprime "N slides gerados em <pasta>". Funções < 50 linhas.

## Aceite (de `frontend/`, Bash)
```
node scripts/campanha-slides.mjs
node -e 'const fs=require("fs"),p="../docs/campanhas/outubro-rosa/instagram/";const f=fs.readdirSync(p).filter(n=>/^slide-\d\d\.png$/.test(n));for(const n of f){const b=fs.readFileSync(p+n);const w=b.readUInt32BE(16),h=b.readUInt32BE(20);if(w!==1080||h!==1350)throw new Error(n+" "+w+"x"+h)}console.log("OK",f.length,"PNG 1080x1350")'
```
Depois abra 3 PNGs (capa, um de número, o de hábitos) com Read e confira legibilidade e corte. Relatório conforme `_REGRAS.md` (≤ 12 linhas).
