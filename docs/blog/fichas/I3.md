# I3 — Link "Conheça a plataforma" na tela de login (Onda 1, Infra)

**Objetivo.** Na tela de login (`frontend/index.html`), a faixa `.welcome-liga` já tem o link "Conheça a LAIFT" (`liga.html`).
Acrescentar um segundo link, "Conheça a plataforma", para `blog.html`, sem quebrar `scripts/e2e/liga.e2e.js` nem os testes de sw/precache/CSP.

## Passo 0 — ler
`docs/blog/fichas/_REGRAS.md`; `frontend/index.html:105-120` (só esse trecho); `frontend/styles.css` (Grep `welcome-liga`, ~linha 840-850);
`frontend/scripts/e2e/liga.e2e.js:135-160` (ele usa `locator('.welcome-liga__link')` em modo estrito: **dois** elementos com essa classe quebram o teste);
Grep `index.html` em `frontend/scripts/*.test.mjs` e em `frontend/sw.js` para ver se algum teste/precache depende do conteúdo do index.

## Dono de (só estes)
- EDITA `frontend/index.html` (só a `div.welcome-liga`)
- EDITA `frontend/styles.css` (só as regras `.welcome-liga*`)
- Proibido: `liga.e2e.js`, `sw.js`, qualquer outro arquivo.

## Requisitos
1. Dentro de `div.welcome-liga`, depois do link existente:
   `<a class="link-btn welcome-liga__blog" href="blog.html">Conheça a plataforma</a>`
   (classe **nova** `welcome-liga__blog`; **não** use `welcome-liga__link` nele). Não altere o aviso nem o link da Liga.
2. `styles.css`: o novo link com o mesmo visual e alvo ≥ 44 px do link da Liga (ex.: selecionar `.welcome-liga__link, .welcome-liga__blog`).
   Se os dois links ficarem lado a lado, que quebrem linha no celular sem rolagem horizontal em 375 px (ex.: `display:flex; flex-wrap:wrap; gap`
   na `.welcome-liga`, conferindo que o aviso continua em linha própria). Nada de estilo inline.
3. Não mude a CSP do `index.html`. Se algum teste exigir versão nova de cache do `sw.js` quando o index muda, **não** mude o `sw.js`: relate.

## Aceite (de `frontend/`, Bash)
```
grep -c 'class="link-btn welcome-liga__blog" href="blog.html"' index.html   # 1
grep -c 'welcome-liga__link' index.html                                     # 1 (continua um só)
node --test scripts/*.test.mjs                                              # verde (anote quantos testes)
node scripts/build.js && node scripts/e2e/run.js liga                       # verde
```
Relatório conforme `_REGRAS.md` (≤ 12 linhas).
