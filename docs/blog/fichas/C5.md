## Requisitos
1. `campanhas.json` = `{ "posts": [ { … } ] }` com: `slug` `outubro-rosa-2026`; `titulo` (≤ 90) ex.: "Outubro Rosa 2026: conhecer, cuidar e saber seus direitos";
   `resumo` (≤ 200); `data` `2026-10-09`; `atualizado_em` `2026-10-09`; `tags` (≤ 5, `^[a-z0-9-]{2,24}$`) ex.: `outubro-rosa`, `cancer-de-mama`,
   `saude-da-mulher`, `prevencao`, `direitos`; `serie` `campanhas`; `ordem_na_serie` 1; `icone` `laco`; `fixado` true; `status` `ativo`;
   `leitura_min` = palavras do texto ÷ 200, arredondado para cima, no máximo 20; `fontes` (cada ≤ 160 caracteres) apontando para os 6 arquivos
   `docs/blog/campanhas/outubro-rosa/fatos-*.md (checado em 2026-10-09)`.
2. `blocos`, nesta ordem: `destaque` tom `atencao` com o aviso do §9 → `p` de abertura (2 frases: o que a pessoa vai encontrar) → `sumario` →
   blocos da parte 1 → parte 2 → parte 3 → parte 4 → `h2` "Fontes" → `referencias` (união das 4 partes, sem repetir `id`, na ordem da 1ª citação)
   → `contato` (`titulo` "Fale com a Liga") → `destaque` tom `atencao` final (mesmo aviso, pode acrescentar "Compartilhe com quem você ama.").
3. Revisão editorial leve: transições entre seções, sem repetir a mesma informação em duas partes, tom uniforme, máximo 3 `destaque` no post.
   Não acrescente fato novo.
4. Conferências finais (todas obrigatórias): emoji só em `habitos[].emoji`; toda `ref`/`#ref-` existe; nenhuma referência com host fora da lista;
   nenhuma palavra proibida do §8.
