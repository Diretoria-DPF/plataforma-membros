# M1 — Módulo de blocos de campanha + testes + exemplo (Onda 1, Motor)

**Objetivo.** Implementar `frontend/scripts/blog-blocos-campanha.js` exatamente como `docs/blog/CAMPANHAS.md` (seções 1, 2, 3, 6 e 8),
com testes e um post-exemplo fictício. A sessão principal pluga o módulo no gerador depois (S1); você **não** edita `build-blog.js`.

`docs/blog/fichas/_REGRAS.md`; `docs/blog/CAMPANHAS.md` (inteiro — é o contrato); `frontend/scripts/build-blog.js` (inteiro, 435 linhas:

## Requisitos do módulo
1. `module.exports = { BLOCOS_CAMPANHA, HOSTS_FONTES, validar, render, checarPost, formatarNumero }` com
   `BLOCOS_CAMPANHA = ['sumario','painel','deck','comparativo','guia','faixas','habitos','referencias']`.
2. `validar(bloco, ctx)` → `string[]` (vazio = ok). `ctx = { blocos, icones }`. Checa tipos, obrigatórios, limites e enums da seção 3,
   `ref` com formato de id, `href` (https, hostname exato em `HOSTS_FONTES`, sem `[<>"'\s]`, ≤ 300 chars), `doi`, `acesso` AAAA-MM-DD,
   `icone` em `ctx.icones` (se `ctx.icones` vier), emoji fora de `habitos[].emoji` (regex `/\p{Extended_Pictographic}/u`),
   `habitos[].emoji` com 1–8 code points e casando a regex. Mensagens curtas em português.
3. `render(bloco, ctx)` → string HTML **exatamente** com as tags/classes/atributos da seção 3. `ctx = { esc, renderInline, icone, avisos, contador, blocos }`.
   Texto marcado (inline) → `ctx.renderInline(texto)`; demais → `ctx.esc(texto)`. `ref` → `<sup class="blog-ref"><a href="#ref-ID" aria-label="Fonte N">N</a></sup>`
   (N = posição no bloco `referencias` de `ctx.blocos`). Ids com `ctx.contador.campanha`. Números com `formatarNumero(v, casas)` =
   `Intl.NumberFormat('pt-BR', {minimumFractionDigits: casas, maximumFractionDigits: casas})`. Barras: `data-v` (3 casas) e `data-p`
   (múltiplo de 5). Data de acesso: "Acesso em 9 de outubro de 2026." (meses por extenso, sem zero à esquerda). Nunca emitir `style=`.
4. `checarPost(blocos)` → `string[]`, regras da seção 1 item 3 do contrato (sumário/referências únicos, refs existentes — inclusive
   `#ref-ID` dentro de textos, ids únicos, emoji só em `habitos[].emoji` em **todos** os blocos, aviso de saúde no topo e entre os 3 últimos).
5. CLI: `node scripts/blog-blocos-campanha.js --checar-parte <arquivo.json>`; o arquivo tem `{ "blocos": [...], "referencias": [...] }`.
   Monta um post falso (`slug: "checagem-parte"`, `serie: "campanhas"`, `icone: "laco"`, `data: "2026-10-09"`, `tags: ["checagem"]`,
   `leitura_min: 5`, `fontes: ["checagem"]`, `titulo`/`resumo` curtos) com os blocos na ordem: `destaque` de aviso (tom `atencao`, texto do
   contrato §9) + `blocos` da parte + bloco `referencias` com os `referencias` (se a parte não trouxer um) + `destaque` de aviso. Assim a parte
   passa na regra do aviso sem opção especial.
   Dentro da função da CLI: `const g = require('./build-blog.js')`; se `g.SERIES.includes('campanhas')` → `g.validatePost(post, { email: null })`
   (checagem completa: frases proibidas, links, render); senão → só `validar` de cada bloco de campanha + `checarPost` e imprime
   "AVISO: plugue S1 ausente; checagem parcial". Imprime "OK (N blocos, M referências)" ou a lista de erros; código de saída 1 se houver erro.
6. Funções < 50 linhas, sem aninhamento > 4 níveis; um objeto `VALIDAR = { tipo: fn }` e `RENDER = { tipo: fn }` como no gerador.

## Requisitos dos testes (mínimo)
Para cada um dos 8 blocos: 1 caso válido (renderiza as classes-chave do contrato) e ≥ 1 inválido (mensagem esperada).
Mais: `href` aceita `https://www.gov.br/inca/x` e recusa `http://www.gov.br/x`, `https://www.gov.br.evil.com/x`, `https://evil.com/x`;
emoji recusado em `deck` e aceito em `habitos[].emoji`; `formatarNumero(78610,0) === '78.610'` e `formatarNumero(84.5,1) === '84,5'`;
`data-p` de 0.845 é `85`; `sumario` lista os `h2` em ordem com `#s-1`, `#s-2`; `checarPost` acusa `ref` inexistente e `#ref-x` inexistente
num `p`; nenhum `render` contém `style=`; texto com `<b>` sai escapado; o `_EXEMPLO-campanha.json` passa em `validar` + `checarPost` sem erros.
Use um `ctx` de teste simples (esc local, `renderInline: esc`, `icone: (id, c) => '<svg class="' + c + '"></svg>'`, `contador: { h2: 0, contato: 0 }`).
