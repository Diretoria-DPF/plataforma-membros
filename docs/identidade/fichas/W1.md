# W1 · Blog instalável (`blog-sw.js`, `blog/instalar.js`, teste)

## Objetivo
"Deixar o blog como opção de download para facilitar o acesso." Torne o blog instalável como app (botão "Instalar" e instrução para
iPhone/iPad) e com leitura offline dos posts já abertos.

## Passo 0
`cd "<RAIZ>/frontend" && ls sw.js pwa.js scripts/pwa.test.mjs blog/manifest.webmanifest ../docs/identidade/CONTRATO.md` (manifest e a linha
`'blog-sw.js'` em `scripts/build.js` vêm da sessão principal; se faltarem, pare e relate). Leia ORDEM.md §Regras e CONTRATO §8 (inteiro).
Padrões: `sw.js` (estrutura, exports, instalação tolerante a falha) e `pwa.js` (`shouldRegister`). Confirme em 2 consultas (WebFetch) os critérios
atuais de instalação: `web.dev/articles/install-criteria` e `developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable`.
Se exigirem algo que o contrato não cobre, relate (não mude o manifest).

## Arquivos-donos (só estes)
- `frontend/blog-sw.js` (novo)
- `frontend/blog/instalar.js` (novo)
- `frontend/scripts/blog-pwa.test.mjs` (novo)

## Requisitos
1. `blog-sw.js` exatamente CONTRATO §8: cache `laift-blog-v1`, precache tolerante, rede primeiro, `chaveDe` (sem `.html`), offline → `/blog/404.html`
   para navegação, ativação que só apaga `laift-blog-*` antigos, `skipWaiting` + `clients.claim`. Para navegação use `fetch(event.request)` e
   devolva a resposta mesmo se for redirecionamento (`opaqueredirect`, não guarda). Exports no Node como `sw.js`.
2. `blog/instalar.js` exatamente CONTRATO §8 (script clássico, sem `import`/`export`; no Node, exporta `ehIos`, `estaInstalado`, `deveRegistrar`).
   Registro: `navigator.serviceWorker.register('/blog-sw.js', { scope: '/blog' })` com `.catch` silencioso, só se `deveRegistrar`. O diálogo do
   iPhone é criado só no primeiro clique, com `createElement`, foco no botão "Entendi" e fecha com Esc (nativo do `<dialog>`).
3. Teste `node:test` (padrão de `scripts/pwa.test.mjs`): manifest do blog (`id`/`start_url`/`scope` = `/blog`, `display` standalone, `short_name` ≤ 12,
   ícones 192/512/maskable existem com o tamanho declarado); `blog-sw.js` (`chaveDe('/blog.html') === chaveDe('/blog')`, `shouldHandle` recusa
   outra origem, POST, Range e `/blog-sw.js`, `isStaleCache` nunca apaga `laift-shell-v3` nem `atlas-*`, `PRECACHE` contém `/blog` e `/blog/404.html`);
   `instalar.js` (`ehIos` com iPhone e com `MacIntel` + toque; `deveRegistrar` falso sob webdriver e em http fora de localhost); `scripts/build.js`
   contém `'blog-sw.js'`. Mínimo 12 asserções.

## Aceite (de `frontend/`)
```bash
node --check blog-sw.js && node --check blog/instalar.js && node --test scripts/blog-pwa.test.mjs scripts/pwa.test.mjs
grep -nE 'innerHTML|insertAdjacentHTML|document\.write|^\s*(import|export)\b' blog-sw.js blog/instalar.js      # nada
head -3 blog-sw.js | grep -q 'Plataforma de Membros LAIFT' && head -3 blog/instalar.js | grep -q 'Plataforma de Membros LAIFT' && echo cabecalho-ok
```
