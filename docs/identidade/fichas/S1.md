# S1 · Prédio da instituição em SVG (`icons/predio-instituicao.svg`)

## Objetivo
"Utilizar uma representação de prédio para simular a instituição, como se fosse um emoji de prédio, só que grande, exibindo todas as
informações detalhadas e a localização no mapa." Desenhe o prédio da UNINASSAU em SVG próprio, estilo emoji, grande e detalhado.

## Passo 0
`cd "<RAIZ>/frontend" && ls icons/ ../docs/identidade/CONTRATO.md`. Leia ORDEM.md §Regras e CONTRATO §6 (parágrafo "Prédio").
Fato de fonte aberta: o edifício "UNINASSAU" no OpenStreetMap (way 1225245762) tem `building:levels=4`.

## Arquivos-donos (só estes)
- `frontend/icons/predio-instituicao.svg` (novo)
- `docs/identidade/capturas/predio-previa.png` (gerado pelo aceite)

## Requisitos
1. Raiz `<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 320 360" width="320" height="360">` com `<title>Prédio da UNINASSAU</title>` e
   `<desc>Ilustração de um prédio de quatro andares com a placa UNINASSAU e o número 358 na entrada.</desc>`.
2. Composição (de trás para frente): placa circular `#e1f4f0` (centro ~160,190, raio ~150) com 2 nuvens `#ffffff`; pino de mapa `#ca545d`
   com miolo `#ffffff` sobre o telhado; corpo do prédio claro (`#fafaf7`/`#edebe5`) com contorno `#1c2333` de 3 a 4 px e cantos arredondados;
   cornija/telhado `#0f6f62`; faixa `#0f6f62` com o texto "UNINASSAU" em `#ffffff` (peso 700, `font-family="Segoe UI, system-ui, -apple-system, Roboto, sans-serif"`,
   `text-anchor="middle"`); 3 andares de janelas (5 por andar, vidro `#e5effc`, 2 ou 3 acesas em `#ffc857`, caixilho `#1c2333`);
   térreo com porta dupla `#0b5349`, puxadores, degraus `#e4e1d8` e plaqueta "358" (`#ffc857`, texto `#1c2333`); 2 árvores (`#7be3a0`/`#1e6b3c`,
   tronco `#8f6b09`); calçada `#e4e1d8` e sombra suave no chão. Use só as cores da paleta de CONTRATO §6.
3. Proibido: `style=""`, `<style>`, `<script>`, `<image>`, `<foreignObject>`, qualquer `href`/`xlink:href` externo, filtros pesados, logotipo
   da UNINASSAU. Formas cheias com cantos arredondados (`rx`), coordenadas inteiras ou com 1 casa. Arquivo ≤ 12 KB.
4. Precisa ler bem a 160 px de largura (celular) e a 320 px; não pode sumir no fundo escuro `#0e1114` (a placa clara resolve).
5. Cabeçalho de copyright não se aplica a `.svg`; ponha um comentário `<!-- Plataforma de Membros LAIFT · © 2026 Daniel Pires Francisco -->` depois da raiz.

## Aceite (de `frontend/`)
```bash
F=icons/predio-instituicao.svg
test $(wc -c < $F) -le 12288 && echo tamanho-ok
grep -nE 'style=|<style|<script|<image|foreignObject|href=' $F     # nada
grep -c '<title>' $F; grep -c '<desc>' $F                          # 1 e 1
node -e '
const { chromium } = require("playwright"); const fs = require("fs");
(async () => { const b = await chromium.launch(); const p = await b.newPage({ viewport: { width: 760, height: 400 } });
const src = "data:image/svg+xml;base64," + Buffer.from(fs.readFileSync("icons/predio-instituicao.svg")).toString("base64");
await p.setContent("<body style=\"margin:0;display:flex\"><div style=\"background:#fafaf7;padding:20px\"><img id=a src=\"" + src + "\" width=320 height=360></div><div style=\"background:#0e1114;padding:20px\"><img src=\"" + src + "\" width=160 height=180></div></body>");
await p.waitForFunction(() => document.getElementById("a").complete);
const w = await p.evaluate(() => document.getElementById("a").naturalWidth);
fs.mkdirSync("../docs/identidade/capturas", { recursive: true });
await p.screenshot({ path: "../docs/identidade/capturas/predio-previa.png" }); await b.close();
console.log(w > 0 ? "ok" : "FALHOU: o SVG não carrega"); process.exit(w > 0 ? 0 : 1); })();'
```
Abra `docs/identidade/capturas/predio-previa.png` (ferramenta Read) e confira: 4 andares, placa legível, número 358, nada cortado.
