"Precisaremos de uma interface moderna" e "em todos os módulos precisaremos da opção de 'voltar', parte superior esquerda em formato de
botão"; no blog, "as opções cadastro, login e início na parte superior". Escreva o CSS compartilhado das páginas públicas (barra, voltar,
botões, seções, rodapé, diálogo de instalação) e o CSS das páginas do processo seletivo e do edital.

## Requisitos
1. `publico.css` cobre exatamente as classes de CONTRATO §1, §10 e o diálogo de §8: `.pub-pagina`, `.pub-pagina main`, `.pub-pular` (visível só no
   foco), `.pub-barra`, `.pub-barra__linha`, `.pub-barra__marca` (logo em placa clara fixa `#fafaf7`, 40 px), `.pub-barra__nav`, `.pub-barra__link`,
   `.pub-barra__link--destaque`, `.pub-voltar`, `.pub-voltar__rotulo`, `.pub-icone`, `.pub-instalar`, `.pub-instalar-dialogo` (+ `::backdrop`),
   `.pub-sec` (+ `h2`, `h3`, `p`, `a`), `.pub-botao`, `--primario`, `--secundario`, `.pub-status[data-estado=fechado|aberto|erro]`, `.pub-rodape` e filhos,
   e a regra de `[hidden]` com `!important` de §10. As regras da barra **não** dependem de `.pub-pagina` (o blog usa a barra sem essa classe).
2. Barra: celular = 2 linhas (linha 1: voltar à esquerda, marca, instalar à direita; linha 2: nav com os links em partes iguais, `overflow-x: auto`
   se não couber); ≥ 760 px = uma linha de 64 px, `position: sticky; top: 0; z-index: 30`, véu de `--layer-0` a 92 % e `backdrop-filter` só em
   `@supports (backdrop-filter: blur(1px))`. Todos os alvos ≥ 44 px. `.pub-voltar` em pílula `--layer-2`, peso 700, ícone + texto.
3. `processo.css` cobre `.ps-*` e `.ed-*` de CONTRATO §3, §4 e §10: topo com selo; passos numerados por contador CSS (círculo 40 px na cor da
   marca); linha do tempo (1 coluna; 3 colunas ≥ 760); `.ps-etapa__tag` por `[data-carater=eliminatoria|classificatoria]`; FAQ (`details` em
   `--layer-2`, raio 24 px, `summary` ≥ 44 px sem marcador nativo, seta desenhada com borda que gira com `transform` em `--dur-fast`); `.ps-cta`
   fixa embaixo com `env(safe-area-inset-bottom)`, raio 24 px no topo, `--elev-2`; `main.ps-conteudo` com `padding-bottom` de §3;
   edital com `.ed-doc` (leitura ~70ch), `.ed-cabecalho`, `.ed-acoes`, `.ed-sumario`, `.ed-secao`, `.ed-tabela` (lista empilhada < 600 px via
   `td::before { content: attr(data-rotulo) }`), `.ed-rodape`; `@media print` de §10 (use as palavras `black` e `white`, não hex).
4. Movimento: só `transform`/`opacity` com `--dur-*`/`--ease-*`; `:active { transform: scale(.98) }` em botões e links-botão; `:hover` só em
   `@media (hover: hover)`. Foco: o de `laift-tokens.css` (não remova `outline`).
5. Sem cor literal (exceto `#fafaf7` da placa da marca); sem `!important` fora da regra de `[hidden]`. Cabeçalho de copyright nos dois.

## Aceite (de `frontend/`) — rode para cada arquivo
```bash
for ARQ in publico.css processo.css; do node -e '
const fs = require("fs"); const arq = process.argv[1]; const css = fs.readFileSync(arq, "utf8"); const erros = [];
const sem = css.replace(/\/\*[\s\S]*?\*\//g, "");
if (!css.startsWith("/*") || !css.includes("Daniel Pires Francisco")) erros.push("cabeçalho de copyright");
for (const m of sem.matchAll(/transition(?:-property)?\s*:\s*([^;}]+)/g)) for (const parte of m[1].split(",")) { const prop = parte.trim().split(/\s+/)[0]; if (!["transform", "opacity", "none"].includes(prop)) erros.push("transition em " + prop); }
for (const m of sem.matchAll(/@keyframes[^{]+\{([\s\S]*?)\}\s*\}/g)) for (const d of m[1].matchAll(/([a-z-]+)\s*:/g)) if (!["transform", "opacity", "animation-timing-function"].includes(d[1])) erros.push("keyframes com " + d[1]);
const tokens = fs.readFileSync("modulos/shared/laift-tokens.css", "utf8");
const definidas = new Set([...tokens.matchAll(/(--[\w-]+)\s*:/g), ...sem.matchAll(/(--[\w-]+)\s*:/g)].map((m) => m[1]));
for (const m of sem.matchAll(/var\((--[\w-]+)/g)) if (!definidas.has(m[1]) && !["--i", "--p"].includes(m[1])) erros.push("variável desconhecida " + m[1]);
if (/#[0-9a-f]{3,8}\b/i.test(sem.replace(/#fafaf7/gi, ""))) erros.push("cor literal (use tokens)");
if (/!important/.test(sem.replace(/\[hidden\][^{]*\{[^}]*\}/g, ""))) erros.push("!important fora da regra de [hidden]");
console.log(arq + ": " + (erros.length ? "FALHOU: " + [...new Set(erros)].join(" | ") : "ok")); process.exit(erros.length ? 1 : 0);' "$ARQ"; done
for C in pub-barra pub-barra__linha pub-barra__marca pub-barra__nav pub-barra__link--destaque pub-voltar pub-icone pub-instalar pub-instalar-dialogo pub-sec pub-botao--primario pub-botao--secundario pub-status pub-rodape pub-pular; do grep -q "\.$C\b" publico.css || echo "FALTA .$C"; done
for C in ps-topo ps-passos ps-linha ps-etapa__tag ps-faq__item ps-faq__pergunta ps-faq__resposta ps-cta ps-cta__fechado ed-doc ed-cabecalho ed-sumario ed-secao ed-tabela ed-rodape; do grep -q "\.$C\b" processo.css || echo "FALTA .$C"; done
grep -c '@media print' processo.css      # 1 ou mais
```
