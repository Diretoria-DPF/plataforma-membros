# J3 · Aviso de nova publicação do blog (`blog-novidade.js`, `blog-novidade.css`, teste)

## Objetivo
"Uma boa possibilidade também será apresentar informações relevantes do blog na página, pois ao abrir a plataforma aparece que possui uma
nova publicação no blog, podendo ser acessada pelo usuário." Mostre a publicação mais recente na tela inicial e as 3 últimas em `/liga`.

## Passo 0
`cd "<RAIZ>/frontend" && ls pwa.js scripts/pwa.test.mjs ../docs/identidade/CONTRATO.md`. Leia ORDEM.md §Regras.
Leia: CONTRATO §0 e §7 (inteiro). Formato do índice: `indiceDe` em `scripts/build-blog.js` (Grep) — `{ total, posts: [{ slug, titulo, resumo, data,
serie, href, fixado, ... }] }`, `href` = `blog/<slug>.html`. Padrão de exportação: `pwa.js`; padrão de teste: `scripts/pwa.test.mjs` (`node:test`, `createRequire`).

## Requisitos
1. JS (IIFE, `'use strict'`, cabeçalho): na carga, para cada `[data-blog-novidade]`, lê `data-blog-indice` (padrão `blog/index.json`) com
   `fetch(url, { cache: 'no-cache' })` (uma vez só, mesmo com 2 contêineres), escolhe com `escolherNovidades`, monta o item de §7 com
   `createElement`/`textContent`, grava o slug visto no clique (`localStorage`, try/catch) e tira o `hidden`. Falha de rede, JSON inválido, lista
   vazia ou item inválido: nada aparece e nada vai para o console.
2. Funções puras exportadas no Node: `escolherNovidades(posts, n)`, `ehNova(post, agoraMs, vistoSlug)` (≤ 14 dias, data `AAAA-MM-DD` em UTC),
   `hrefValido(href)` (`^blog\/[a-z0-9-]+\.html$`), `rotuloSerie(serie)`.
3. CSS (só `.blog-novidade*`, tokens, sem cor literal, movimento só `transform`/`opacity`):
   - `--faixa` (tela inicial, dentro de `.welcome-liga`, que é `flex-wrap`): `flex: 0 0 100%`; item em linha única que quebra, `--layer-2`, raio 20 px,
     ≥ 44 px, selo pequeno em `--laift-primary-soft`/`--laift-primary`, título peso 700, meta `--laift-muted`.
   - `--cartoes` (`/liga`): `ul.blog-novidade__lista` em grade 1 / 3 colunas ≥ 900; cartão `--layer-2`, raio 24 px, `--elev-1`, título, resumo
     (3 linhas com `-webkit-line-clamp`), meta; `@media (hover: hover)` sobe `translateY(-2px)`.
   - `.blog-novidade[hidden] { display: none !important; }`.
4. Teste (`node:test`): ordem por data; empate a favor de `campanhas`; `n` respeitado; item com `href` `javascript:`/`https://`/`../` descartado;
   `ehNova` verdadeiro com 3 dias e falso com 20 dias ou slug já visto; `rotuloSerie('campanhas') === 'Publicações'`. Mínimo 8 asserções.

## Aceite (de `frontend/`)
```bash
node --check blog-novidade.js && node --test scripts/blog-novidade.test.mjs
grep -nE 'innerHTML|insertAdjacentHTML|document\.write|console\.(log|error)' blog-novidade.js      # nada
node -e '
const css = require("fs").readFileSync("blog-novidade.css", "utf8").replace(/\/\*[\s\S]*?\*\//g, ""); const erros = [];
for (const m of css.matchAll(/transition(?:-property)?\s*:\s*([^;}]+)/g)) for (const parte of m[1].split(",")) { const prop = parte.trim().split(/\s+/)[0]; if (!["transform", "opacity", "none"].includes(prop)) erros.push("transition " + prop); }
if (/#[0-9a-f]{3,8}\b/i.test(css)) erros.push("cor literal");
if (/\.(?!blog-novidade)[a-z][\w-]*\s*[{,]/.test(css.replace(/\.welcome-liga\b/g, ""))) erros.push("classe fora do prefixo");
console.log(erros.length ? "FALHOU " + erros.join(" | ") : "ok"); process.exit(erros.length ? 1 : 0);'
head -3 blog-novidade.css | grep -q 'Plataforma de Membros LAIFT' && head -3 blog-novidade.js | grep -q 'Plataforma de Membros LAIFT' && echo cabecalho-ok
```
