# V1 · Botão "Voltar" nos módulos do app (`voltar-app.js`, `voltar-app.css`, teste)

## Objetivo
"Em todos os módulos precisaremos da opção de 'voltar', deverá ficar parte superior esquerda em formato de botão, para conseguir retornar
para a tela principal ou tela anterior." Ponha um "Voltar" no topo de cada painel do app (menos o Início) que volta ao painel anterior.

## Requisitos
1. JS (IIFE, `'use strict'`, cabeçalho): na carga (`DOMContentLoaded` ou já carregado), insere o botão de §9 com `createElement`/`createElementNS`
   como primeiro filho de cada `#app-root .app-main > section` exceto `#panel-home`. Ouve `laift:panelchange` e `laift:modulechange` no `document`.
   Clique segue a regra de §9 (pilha imutável, escopo membro/admin, reserva, `#btn-exit-admin-mode`), com `window.App.showPanel`. Atualiza o
   `aria-label` ("Voltar para <nome>") a cada troca. Sem `innerHTML`. Exporta no Node: `escopoDe`, `registrar`, `destinoDoVoltar`.
2. CSS (só `.app-voltar*`, tokens, sem cor literal): pílula ≥ 44 px, `inline-flex`, gap 6 px, ícone 20 px (`fill: none; stroke: currentColor;
   stroke-width: 2`), `--layer-2`/`--laift-text`, peso 700, `margin: 0 0 12px`; seletor `.app-main > section > .app-voltar` para vencer o `button`
   global (`width: auto`, `background`, `color`, `border: 0`, `box-shadow: none`); `:active` com `scale(.98)`; `:hover` só em `@media (hover: hover)`;
   `.app-voltar[hidden] { display: none !important; }`.
3. Teste `node:test`: `escopoDe` (admin/membro); `registrar` não muta a entrada, ignora repetido, zera na troca de escopo e no `panel-home`, corta em 20;
   `destinoDoVoltar` (anterior; sem anterior → `panel-home`; admin → `panel-admin-dashboard`; no dashboard sem anterior → `{ sairDoAdmin: true }`).
   Mínimo 10 asserções.

## Aceite (de `frontend/`)
```bash
node --check voltar-app.js && node --test scripts/voltar-app.test.mjs
grep -nE 'innerHTML|insertAdjacentHTML|document\.write' voltar-app.js      # nada
node -e '
const css = require("fs").readFileSync("voltar-app.css", "utf8"); const sem = css.replace(/\/\*[\s\S]*?\*\//g, ""); const erros = [];
if (!css.includes("Plataforma de Membros LAIFT")) erros.push("cabeçalho");
for (const m of sem.matchAll(/transition(?:-property)?\s*:\s*([^;}]+)/g)) for (const parte of m[1].split(",")) { const prop = parte.trim().split(/\s+/)[0]; if (!["transform", "opacity", "none"].includes(prop)) erros.push("transition " + prop); }
if (/#[0-9a-f]{3,8}\b/i.test(sem)) erros.push("cor literal");
if (!/\.app-main\s*>\s*section\s*>\s*\.app-voltar/.test(sem)) erros.push("seletor que vence o button global");
console.log(erros.length ? "FALHOU " + erros.join(" | ") : "ok"); process.exit(erros.length ? 1 : 0);'
```
