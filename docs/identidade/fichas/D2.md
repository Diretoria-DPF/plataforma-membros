## Requisitos
1. Só classes `lp-*` de CONTRATO §2 e §6 (as `pub-*` são do `publico.css`; não as redefina, só componha com elas, ex.: `.lp-processo.pub-sec`).
   Liste no topo, em comentário, o mapa de seções e os pontos de quebra (600, 760, 900, 1024 px).
2. Hero `.lp-hero`: celular em 1 coluna (marca acima do texto, 112 px), ≥ 900 em 2 colunas (texto | marca de 168 px); fundo `--layer-1` com dois
   `radial-gradient` de `color-mix(in srgb, var(--laift-primary) 12%, transparent)`; raio 32 px; `.lp-hero__sigla` `clamp(3rem, 12vw, 5.5rem)`
   peso 800 cor `--laift-primary` `line-height: 1`; `.lp-hero__nome` `clamp(1.125rem, 3.6vw, 1.5rem)` peso 700, `display: block`, `max-width: 28ch`;
   lema e oferta em `--laift-muted`; `.lp-hero__acoes` em linha que quebra, gap 12 px; `.lp-hero__local` como link-chip ≥ 44 px.
   Entrada do hero: `@keyframes` com `opacity` 0→1 e `translateY(var(--move-md))`→0, `--dur-slow`, `--ease-out`, atraso escalonado por `nth-child`.
3. `.lp-secoes`: `position: sticky; top: 0` (≥ 760: `top: 64px`), fundo `--layer-0` a 92 %, chips `.lp-secoes__item` em pílula ≥ 44 px roláveis
   na horizontal (`overflow-x: auto`, `scrollbar-width: thin`), z-index 20.
4. `.lp-cards` / `.lp-card` (cards verticais): celular = carrossel `display: flex; gap: 16px; overflow-x: auto; scroll-snap-type: x mandatory;
   overscroll-behavior-x: contain`, cartão `flex: 0 0 min(78%, 280px); min-height: 320px; scroll-snap-align: start`, em `--layer-2`, raio 28 px,
   `--elev-1`, emoji de 2,75rem no topo, título 1,125rem, texto `--laift-muted`; ≥ 1024 = grade `repeat(4, minmax(0, 1fr))` sem rolagem.
   `@media (hover: hover)`: cartão sobe `translateY(-4px)` com `transition: transform`. `.lp-cards:focus-visible` com o anel do token.
5. `.lp-areas__lista` (1 / 2 ≥ 600 / 4 ≥ 1024 colunas), `.lp-area` em `--layer-2` raio 24 px, emoji num círculo de 52 px `--layer-1`, nome peso 700,
   texto pequeno `--laift-muted`.
6. `.lp-funciona__grade` (2 colunas ≥ 900), `.lp-compromisso` com marcador de check desenhado por borda (sem imagem) na cor da marca,
   `.lp-beneficios__lista` em grade de 2 colunas ≥ 600, `.lp-beneficio` em `--layer-2`; `.lp-diferencial` em `--laift-primary-soft` com texto
   `--laift-text`; `.lp-disponibilidade` em `--laift-muted`.
7. `.lp-processo` (texto + Lia de 120 px à direita ≥ 760; Lia escondida < 600), `.lp-processo__passos` numerados por contador (3 em linha ≥ 760),
   `.lp-edital`, `.lp-contato__lista` (1 / 3 colunas ≥ 760) com `.lp-contato__item` em bloco ≥ 64 px, ícone 28 px, rótulo e valor em 2 linhas.
8. `.lp-instituicao__grade` (2 colunas ≥ 900), `.lp-instituicao__predio` `width: 100%; max-width: 320px; height: auto` centralizado,
   `.lp-instituicao__sigla` (rótulo em caixa-alta `--laift-primary`), `.lp-mapa__links` em linha que quebra (links ≥ 44 px),
   `.lp-mapa` (`aspect-ratio: 4 / 3`, ≥ 760 `16 / 9`, `--layer-2`, raio 28 px, `overflow: hidden`), `.lp-mapa__capa` centralizada com o pino
   grande, `.lp-mapa__frame` 100 % × 100 % `border: 0`, `.lp-mapa__credito` pequeno.
9. Revelação ao rolar só dentro de `@media (prefers-reduced-motion: no-preference) { @supports (animation-timeline: view()) { … } }`, em
   `.lp-conteudo > .pub-sec`: `opacity`/`transform` com `animation-timeline: view(); animation-range: entry 0% cover 25%`.
10. Nada pode criar rolagem horizontal da página em 375 px (`min-width: 0` nos itens de grade; imagens `max-width: 100%`).
11. Sem cor literal (exceto `#fafaf7` da placa); sem `!important`; cabeçalho de copyright.

## Aceite (de `frontend/`)
```bash
node -e '
const fs = require("fs"); const arq = process.argv[1]; const css = fs.readFileSync(arq, "utf8"); const erros = [];
const sem = css.replace(/\/\*[\s\S]*?\*\//g, "");
if (!css.startsWith("/*") || !css.includes("Daniel Pires Francisco")) erros.push("cabeçalho de copyright");
for (const m of sem.matchAll(/transition(?:-property)?\s*:\s*([^;}]+)/g)) for (const parte of m[1].split(",")) { const prop = parte.trim().split(/\s+/)[0]; if (!["transform", "opacity", "none"].includes(prop)) erros.push("transition em " + prop); }
for (const m of sem.matchAll(/@keyframes[^{]+\{([\s\S]*?)\}\s*\}/g)) for (const d of m[1].matchAll(/([a-z-]+)\s*:/g)) if (!["transform", "opacity", "animation-timing-function"].includes(d[1])) erros.push("keyframes com " + d[1]);
const tokens = fs.readFileSync("modulos/shared/laift-tokens.css", "utf8");
const definidas = new Set([...tokens.matchAll(/(--[\w-]+)\s*:/g), ...sem.matchAll(/(--[\w-]+)\s*:/g)].map((m) => m[1]));
for (const m of sem.matchAll(/var\((--[\w-]+)/g)) if (!definidas.has(m[1]) && !["--i", "--p"].includes(m[1])) erros.push("variável desconhecida " + m[1]);
if (/#[0-9a-f]{3,8}\b/i.test(sem.replace(/#fafaf7/gi, ""))) erros.push("cor literal (use tokens)");
if (/!important/.test(sem)) erros.push("!important");
if (/\.(liga|pub)-[a-z]/.test(sem.replace(/\.pub-sec\b/g, ""))) erros.push("classe fora do prefixo lp- (só .pub-sec pode ser composta)");
console.log(arq + ": " + (erros.length ? "FALHOU: " + [...new Set(erros)].join(" | ") : "ok")); process.exit(erros.length ? 1 : 0);' liga.css
for C in lp-hero lp-hero__sigla lp-hero__nome lp-hero__lema lp-hero__oferta lp-hero__acoes lp-hero__local lp-hero__marca lp-secoes lp-secoes__item lp-cards lp-card lp-card__emoji lp-areas__lista lp-area lp-funciona__grade lp-compromisso lp-beneficio lp-diferencial lp-processo lp-processo__passos lp-contato__item lp-instituicao__grade lp-instituicao__predio lp-mapa lp-mapa__capa lp-mapa__frame lp-mapa__links lp-emoji; do grep -q "\.$C\b" liga.css || echo "FALTA .$C"; done
grep -c 'animation-timeline' liga.css     # 1 ou mais, sempre dentro de @supports
```
