# H1 · Página "Conheça a LAIFT" (`liga.html`)

## Objetivo
"O módulo da tela inicial: Conheça a LAIFT — faremos dessa sessão a identidade digital da liga." Reescreva `liga.html` com a introdução
(nome, frase, oferta, botão do processo seletivo), Quem somos em cards verticais, Áreas de interesse, Como funciona (compromissos e
benefícios), processo seletivo, edital, contato, a instituição (prédio e mapa) e o blog. Troque também o topo do `blog/404.html` pela
mesma barra pública ("cadastro, login e início na parte superior" + "voltar").

## Passo 0
`cd "<RAIZ>/frontend" && ls liga.html blog/404.html ../docs/identidade/CONTRATO.md`. Leia ORDEM.md §Regras.
Leia: CONTRATO §0, §0.1, §0.2, §0.3, §1, §2, §6 (marcação), §11 (textos de `liga.html`). **Substitua o `liga.html` inteiro.**
Os arquivos de CSS/JS citados são escritos por outras fichas ao mesmo tempo: siga só os nomes do contrato.

## Arquivos-donos (só estes)
- `frontend/liga.html` (reescrito)
- `frontend/blog/404.html` (só o `<head>` e o topo; o conteúdo da página continua)

## Requisitos
1. `<head>` exatamente na ordem de §0.2 (CSP de `liga.html` em §0.1, com `frame-src https://www.openstreetmap.org`; canonical `https://laift.com.br/liga`;
   `liga.css` e `blog-novidade.css`), mais o JSON-LD de §2. Sem `styles.css`.
2. Corpo exatamente como §2 + §6: `body.pub-pagina.lp-pagina`, `a.pub-pular`, `header.pub-barra` (variante da Liga: voltar `href="./"`, marca `liga.html`,
   links Início `./`, Blog `blog.html`, Entrar `./#entrar`, Cadastrar `./#cadastro`), `nav.lp-secoes` (8 itens), `main#conteudo.lp-conteudo` com as seções
   na ordem `#topo`, `#quem-somos`, `#areas`, `#como-funciona`, `#processo`, `#edital`, `#contato`, `#instituicao`, `#blog`, e `footer.pub-rodape`.
3. Textos de §11, sem trocar fatos: 7 cartões, 8 áreas, 5 compromissos, 6 benefícios, diferencial, leads. Todo emoji em `span.lp-emoji[aria-hidden=true]`.
4. Hero: `#liga-status` nasce "fechado"; `#liga-cta-processo` com `data-se-aberto hidden`; link secundário com `data-se-fechado`.
5. Instituição exatamente como §6 (prédio em `<img src="icons/predio-instituicao.svg">`, botão `.lp-mapa__carregar` nasce `hidden`, links com `&amp;`).
6. Blog: `div.blog-novidade.blog-novidade--cartoes[data-blog-novidade="3"][hidden]` + link "Ir para o blog".
7. Links externos com `target="_blank" rel="noopener noreferrer"` e o `span.laift-sr-only` "(abre em nova aba)". Um único `h1`; `h2` por seção; `h3` dentro.
8. Fim do `<body>`: `static-page.js`, `liga.js`, `liga-mapa.js`, `blog-novidade.js` (todos `defer`). Sem `style=""`, sem `on*=`, sem script inline.
9. `blog/404.html` (mesma barra, variante do blog, CONTRATO §0.1, §0.3 e §1): CSP do blog (`worker-src 'self'`); acréscimos do `<head>` de §0.3;
   `header.blog-topo` → `header.pub-barra` do blog (voltar `href="/blog.html"`, marca `/blog.html` "Blog LAIFT", `/`, `/#entrar`, `/#cadastro`,
   `.pub-instalar[data-instalar][hidden]`); fim do `<body>` com `/static-page.js` e `/blog/instalar.js` (`defer`). O resto do 404 não muda.

## Aceite (de `frontend/`)
```bash
grep -c 'style="' liga.html                     # 0
grep -nE ' on[a-z]+="' liga.html                # nada
grep -nE '<script[^>]*>' liga.html | grep -v 'src=' | grep -v 'application/ld+json'   # nada
grep -niE 'em revis|planejad|proposta|pendente|a definir|pituba|styles\.css' liga.html  # nada
grep -F 'frame-src https://www.openstreetmap.org' liga.html && grep -F 'https://www.instagram.com/laift.liga"' liga.html
node -e '
const { chromium } = require("playwright"); const fs = require("fs");
(async () => { const b = await chromium.launch(); const p = await b.newPage();
await p.setContent(fs.readFileSync("liga.html", "utf8"), { waitUntil: "domcontentloaded" });
const r = await p.evaluate(() => { const q = (s) => document.querySelectorAll(s).length;
  const ordem = [...document.querySelectorAll("main > section")].map((s) => s.id).join();
  const ext = [...document.querySelectorAll("a[target=_blank]")].filter((a) => !/noopener/.test(a.rel) || !a.querySelector(".laift-sr-only")).length;
  const emojiSolto = [...document.querySelectorAll(".lp-emoji")].filter((e) => e.getAttribute("aria-hidden") !== "true").length;
  const json = [...document.querySelectorAll("script[type=\"application/ld+json\"]")].every((s) => { try { JSON.parse(s.textContent); return true; } catch (e) { return false; } });
  return { h1: q("h1"), ordem: ordem === "topo,quem-somos,areas,como-funciona,processo,edital,contato,instituicao,blog", secoes: q(".lp-secoes__item"),
    cards: q(".lp-card"), areas: q(".lp-area"), compromissos: q(".lp-compromisso"), beneficios: q(".lp-beneficio"), ext, emojiSolto, json,
    cta: q("#liga-cta-processo[data-se-aberto][hidden]"), fechado: q("[data-se-fechado]"), status: q("#liga-status[data-estado=fechado]"),
    voltar: q("header.pub-barra a.pub-voltar[data-history-back]"), mapa: q("#mapa-instituicao .lp-mapa__carregar[hidden]"), app: q("a[data-mapa-app][href^=\"geo:\"]"),
    predio: q("img.lp-instituicao__predio[alt][src=\"icons/predio-instituicao.svg\"]"), blog: q("[data-blog-novidade=\"3\"][hidden]"),
    cadastro: q("a[href=\"./#cadastro\"]"), entrar: q("a[href=\"./#entrar\"]"), iframe: q("iframe") }; });
const ok = r.h1 === 1 && r.ordem && r.secoes === 8 && r.cards === 7 && r.areas === 8 && r.compromissos === 5 && r.beneficios === 6 && r.ext === 0 && r.emojiSolto === 0 && r.json
  && r.cta === 1 && r.fechado >= 1 && r.status === 1 && r.voltar === 1 && r.mapa === 1 && r.app === 1 && r.predio === 1 && r.blog === 1 && r.cadastro >= 1 && r.entrar >= 1 && r.iframe === 0;
console.log(ok ? "ok" : "FALHOU " + JSON.stringify(r)); await b.close(); process.exit(ok ? 0 : 1); })();'
F=blog/404.html; for T in 'class="pub-barra"' 'class="pub-voltar" href="/blog.html"' 'data-history-back' 'href="/#entrar"' 'href="/#cadastro"' 'data-instalar' \
  'rel="manifest" href="/blog/manifest.webmanifest"' 'href="/icons/favicon-32.png"' 'href="/icons/icon-192.png"' 'apple-touch-icon' \
  'href="/publico.css"' 'src="/static-page.js"' 'src="/blog/instalar.js"' "worker-src 'self'" 'blog-404__atalho'; do grep -qF "$T" $F || echo "FALTA em $F: $T"; done
grep -c 'class="blog-topo"' blog/404.html     # 0
```
(O teste `class="pub-voltar" href="/blog.html"` pede essa ordem de atributos; mantenha `data-history-back` e `aria-label` depois do `href`.)
