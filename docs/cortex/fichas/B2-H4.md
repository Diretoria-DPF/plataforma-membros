# B2-H4 · Instantâneo na CI e reserva versionada (Haiku 5.5) — onda 1

**Objetivo:** o script que a CI roda antes do build para buscar o catálogo público na API e gravar `recente.json`, e a reserva commitada que vale quando a API falha.
**Dono de:** novos `frontend/scripts/fetch-biblioteca.mjs`, `frontend/scripts/fetch-biblioteca.test.mjs`, `frontend/biblioteca/conteudo/reserva.json`. Regras: `fichas/ORDEM.md`.
**Depende de:** nada (formato da resposta em `docs/cortex/CONTRATO-B1.md` §4.1, linha `apiLearnLibraryPublicCatalog`).

## Passos
1. Leia `docs/cortex/CONTRATO-B2.md` §2.1 (itens 1 e 2). Modelo de chamada à API pela CI: `tools/ci/smoke.mjs:83-96` (`verificarApi`) (`POST {action, args}`).
2. `reserva.json` = exatamente `{"versao":1,"enabled":false,"generatedAt":"2026-10-10T00:00:00Z","topics":[],"items":[]}` + quebra de linha final.
3. **Teste primeiro** (`fetch` falso injetado; diretório temporário). Exporte `buscar({ apiUrl, out, fetchImpl, timeoutMs })` → `{ gravado, motivo }`. Casos: resposta boa grava `{ versao:1, enabled, generatedAt, topics, items }` (sem nenhum campo extra que a API mande); `success:false`, HTTP 500, JSON inválido, tempo esgotado e `items` que não é array → não grava, não lança, devolve o motivo; `apiUrl` que não seja `https://` → recusa; o corpo enviado é só `{"action":"apiLearnLibraryPublicCatalog","args":[]}` (nada de token nem cookie, `credentials:'omit'`).
4. CLI: `node scripts/fetch-biblioteca.mjs --api <url> --out <arquivo>`; padrão `--out biblioteca/conteudo/recente.json`; falha imprime `::warning::Biblioteca: <motivo>; o build usa a reserva.` e sai com 0.
