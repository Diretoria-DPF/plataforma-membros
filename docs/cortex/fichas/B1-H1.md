# B1-H1 · Identificadores DOI/PMID (Haiku 5.5) — onda 1

**Objetivo:** uma função pura que transforma o texto colado (DOI, PMID ou link aceito) em `{ kind, value }` e recusa todo o resto, mais os montadores de link.
**Dono de:** novos `worker/src/library/identifiers.js`, `worker/test/libraryIdentifiers.test.js`. Regras: `fichas/ORDEM.md`.
**Depende de:** nada.

## Passos
1. Leia `docs/cortex/CONTRATO-B1.md` §7 (bloco "Identificadores") e §5 ("Links"). Modelo de erro: `worker/src/errors.js:22` (`ValidationError`); modelo de link: `worker/src/research/scholarlyClient.js:28-32`.
2. **Teste primeiro.** Exportações e casos:
   - `DOI_RE = /^10\.[0-9]{4,9}\/[-._;()/:a-z0-9]+$/` e `PMID_RE = /^[1-9][0-9]{0,9}$/`, `UUID_RE` (cópia de `worker/src/services/featureFlagService.js:33`), `isUuid(v)`.
   - `parseIdentifier(text)` → `{ kind:'doi', value }` ou `{ kind:'pmid', value }`. Aceita: `10.1371/journal.pone.0000308`, ` DOI:10.1038/Nature12373 ` (vira minúsculo), `https://doi.org/10.1000/a(b)c`, `https://dx.doi.org/10.1000%2Fxyz` (decodifica uma vez), `12345678`, `https://pubmed.ncbi.nlm.nih.gov/12345678/`, `https://europepmc.org/article/MED/12345678`, `https://europepmc.org/abstract/MED/12345678`. Recusa (lança `ValidationError('Informe um DOI (ex.: 10.1000/xyz) ou um PMID (só números).')`): vazio, não-string, `> 300` caracteres, `http://doi.org/...`, `https://doi.org.evil.com/10.1/x`, `https://evil.com/?u=https://doi.org/10.1000/x`, `javascript:alert(1)`, `0123`, `10.12/x` (prefixo curto), DOI com `<` ou espaço no meio, DOI > 200, link da SciELO.
   - `doiLandingUrl(doi)` = `https://doi.org/` + segmentos com `encodeURIComponent`; `pubmedLandingUrl(pmid)` = `https://pubmed.ncbi.nlm.nih.gov/<pmid>/`; `pmcUrl(pmcid)` = `https://pmc.ncbi.nlm.nih.gov/articles/<PMCnnn>/` ou `null` se não casar `^PMC\d{1,10}$`.
3. Rode e veja falhar. Escreva o código (sem dependências além de `../errors.js`). Rode de novo.
