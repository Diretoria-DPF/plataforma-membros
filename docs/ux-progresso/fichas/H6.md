2. `ux.css`: com Edit, insira o conteúdo inteiro de `../docs/ux-progresso/fichas/anexos/ux-entrada.css.txt` logo **antes** da linha
   `/* ---------- Painel Início ---------- */` (aparece uma vez). Nada mais muda no `ux.css`.
3. Crie `entrada.js` (raiz de `frontend/`): cabeçalho de copyright (ORDEM regra 6); comentário
   `// Tela de entrada e cadastro (index.html, #public-shell): "Mostrar senha" e foco no título ao trocar de tela.`
   `// Contrato: docs/ux-progresso/CONTRATO.md §6.4. Roda depois de app.js (o showPublicScreen dele troca a tela; aqui só o foco).`
   Script clássico no padrão UMD (`(function (root) { 'use strict'; … })(typeof self !== 'undefined' ? self : this);`) com:
   - `aplicar(doc, caixa)`: `campo = doc.getElementById(caixa.getAttribute('data-senha-visivel'))`; se existe, `campo.type = caixa.checked ? 'text' : 'password'`.
   - `esconder(doc, caixa)`: `caixa.checked = false; aplicar(doc, caixa);`
   - `focarTitulo(doc, win, idTela)`: `win.scrollTo(0, 0)`; `h1` de `doc.getElementById(idTela)`; se existe, `setAttribute('tabindex', '-1')` e `focus({ preventScroll: true })`.
   - `iniciar(doc, win)`: para cada `input[type="checkbox"][data-senha-visivel]` → `change` chama `aplicar`; se `caixa.form`, `submit` chama
     `esconder` e `reset` chama `win.setTimeout(() => esconder(doc, caixa), 0)`. Para cada `#public-shell [data-nav]` → `click` chama
     `focarTitulo(doc, win, botao.getAttribute('data-nav'))`. Use `Array.prototype.forEach.call(doc.querySelectorAll(…), …)`.
   - Fim: no Node `module.exports = { aplicar, esconder, focarTitulo, iniciar }; return;`; no navegador, se `root.document.readyState === 'loading'`,
     `DOMContentLoaded` → `iniciar(root.document, root)`; senão `iniciar(root.document, root)` direto.
4. Rode os testes até VERDE.
